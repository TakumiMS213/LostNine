# シナリオ CSV 編集ガイド

## 開く・保存する

Unityの **Scenario System > CSV Scenario Editor** を開きます。本文・演出、シークエンス、章ごとの進行、共通素材をこの画面で編集します。

- 初回は「既存データをCSVへ移行して開く」を選びます。既存シナリオとMainの進行設定を取り込みます。既存CSVは上書きしません。
- 通常の保存先は `Assets/ScenarioCSV` です。`scenarios.csv` が本文・演出・進行、`assets.csv` が素材の対応表です。
- **保存**はCSVだけを更新します。ゲームに反映するには **保存して再生データに反映** を押します。
- **検証**で欠落参照、ID重複、不正な数値、分岐・ループ等を確認できます。検証エラーがあるデータは反映しません。
- 「元に戻す」「やり直す」は編集中の操作に使えます。反映後に内容を戻す場合も、CSVを直して再度反映します。

移行後のSOは再生用です。管理対象SOのInspectorは読み取り専用になり、CSV編集画面へのボタンを表示します。`Generated` 内のアセットと `bindings.json` は自動管理されるため、手作業で変更・削除しません。

## 本文と演出

「シナリオ本文・演出」でシナリオを選びます。本文は1回の表示につき1行です。選択行の後へ挿入でき、複製・削除・上下移動もできます。

- 話者と本文を入力し、立ち絵・背景・ボイス・位置・演出を候補から選びます。
- 1回に表示する本文内の改行は、その行の本文欄に入力します。次のクリックで表示するセリフは別の行にします。
- 「複数行貼り付け」では、表計算ソフトからコピーした「話者」「本文」の2列をまとめて挿入できます。1列なら本文として扱います。引用符で囲まれたセル内改行にも対応します。
- 会話の途中へ演出を追加するときは「行を挿入」から「演出」を選びます。演出の種類によって必要な設定を表示します。
- 演出行は演出開始後すぐ次へ進みます。終了まで待ちたい場合は、その後に **待機** 行を置き、秒数を指定します。

空欄は直前の設定を引き継ぐ指定ではありません。

| 項目 | 空欄・既定値の意味 |
| --- | --- |
| 立ち絵・ボイス・表示画像 | 指定なし |
| 背景 | シナリオ用スチルを表示せず、背面の通常背景を使用 |
| 立ち絵位置 | Center |
| 本文の表示速度 | 0ならゲーム既定値 |
| オーバーレイ表示秒数 | 0以下ならクリック待ち |
| 待機秒数 | 0なら時間待ちなし |
| 終了後のシナリオ | 指定なし。ループが有効なら現在のシナリオを繰り返す |
| シナリオID | 直接参照専用なら空欄可。IDで検索するシナリオには設定が必要 |

## 進行・選択肢

「シークエンス」で実行する手順を編集し、「章・フェーズの進行」で対応するシークエンスを選びます。選択肢や各手順の詳細設定も、同じ画面内で編集できます。

移行時に見つかった参照切れステップは「参照切れ（スキップ）」として元の参照情報を保持します。種類を変更して差し替えるか、不要なら行を削除できます。反映済みのシナリオ・シークエンス自体の行削除は、既存参照を残したまま消さないよう拒否します。

新しいシナリオ・シークエンスを参照先として使う場合は、一度保存・反映してください。反映後に選択肢や手順の参照候補へ加わります。選択肢の移動先を「なし」にすると、その選択で現在のシナリオを終了します。

## 共通素材の差し替え

「共通素材」で素材を登録し、表示名を付けます。同じ登録素材を複数行から使うと、この一覧で差し替えた内容をまとめて反映できます。特定の行だけ変える場合は別の素材を登録し、その行の候補から選び直します。

BGM・SEは対応する `Resources/Audio/BGM`・`Resources/Audio/SE` 内の音声から選びます。差し替え先の音声も対応するフォルダーへ置いてください。再生データ自体の参照は共通素材画面で差し替えできません。

## 外部の表計算ソフトで編集する

CSV自体はプルダウンの設定を保存できません。候補選択にはUnityの編集画面を使います。本文などはUTF-8 CSVとして外部編集できます。

- 先頭の版情報とヘッダーを保持します。列名・列順を変更しません。
- `id`・`owner`・`kind`・`type`・`source`・`data` は管理用です。新しい行はUnityで作成するとID等が自動設定されます。既存の行IDをそのまま複製すると重複エラーになります。
- カンマ、引用符、改行を含むセルはCSVの引用符で囲みます。セル内の `"` は `""` として保存します。表計算ソフトのCSV保存を使えば通常は自動処理されます。
- 本文の前後空白、セル内改行、TMPタグを保持します。数値に見える本文やIDを表計算ソフトが自動変換しないよう、文字列として読み込みます。
- Unityで編集中に外部CSVが変更されると、上書き保存を停止します。外部の変更と編集中の内容を確認してから「読込」で読み直してください。
- 外部編集後も「検証」と「保存して再生データに反映」が必要です。
